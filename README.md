# TechWorld-with-Nana-DevOps-Bootcamp
This project is a gateway for my notes, and exercises for Nana Janashia's [DevOps Bootcamp](https://www.techworld-with-nana.com/devops-bootcamp). 
This bootcamp is comprises 16 modules:

1. [Overview and Intro to DevOps](https://github.com/MrStewartSalmon/DevOps-Bootcamp01-Introduction-to-DevOps/tree/main)
2. [Operating Systems & Linux Basics](https://github.com/MrStewartSalmon/DevOps-Bootcamp02-Operating-Systems-Linux-Basics)
3. Version Control with Git
4. Build & Package Manager Tools (Maven, Gradle)
5. Cloud & IaaS
6. Artifact Repository Manager (Nexus)
7. Containers with Docker
8. Build Automation with Jenkins (CI/CD)
9. AWS Services
10. Container Orchestration with Kubernetes
11. Kubernetes on AWS
12. Infrastructure as Code with Terraform
13. Programming Basics (Python)
14. Automation with Python
15. Configuration Management with Ansible
16. Monitoring with Prometheus
